# 口语连续执行

先按[准备说明](SETUP.md)核对设备、UID、唯一副屏及已校准的 1440×3200 布局，再使用[固定版本副本](WORKER.md)。一个设备只由一个执行会话操作。设置 `UCAMPUS_WORK` 为本次证据目录；用户要求快模式时设置 `UCAMPUS_SKIP_SCORE=1`。

## 范例跟读

副屏的无障碍树仅包含当前可见内容。先有界滚动到列表底部，收集并核对完整的、无重复的英文句子数组，再回到实际断点；不从当前半屏猜整组数量。所有 WAV 按文本散列缓存，可提前合成。

```powershell
python <固定副本>/training_session.py --port 8794 --display-id <逻辑ID> --capture-display-id <SurfaceFlingerID> --uid <本次UID> followread --sentences <完整句子数组.json> --start-at <首个待录句序号>
```

同一进程复用控件连接和缓存，稳定滚动后通过语义点击展开，核对当前句与录音按钮。点击、滚动、截图都绑定本次副屏；不会使用主屏 UI dump 补全列表。录音先等实际录音状态和已校准画面，再直送 PCM；已自动停止时不重复点击。

列表最后一行可能无法继续上滚，完整文字落在画面 3000 像素以内时允许先语义展开；不能要求未展开文字始终位于旧 2400 像素阈值以上。录音标签仍在屏幕外时只上滚一次，不重复展开点击。标签需连续两次稳定，注入 ready 后再读稳定坐标，避免展开动画造成旧坐标失效。实际校准允许麦克风 600 < y < 2900，且标签必须完整位于画面 3000 像素以内，原有句子绑定、187 像素偏移和录音像素检查保持。

快模式跳过分数读取，但仍等待「重录」入口恢复，确认本句可继续交互后才切换。实测在「已提交，等待评分」时立即切句会丢失录音；这个等待属于保存门控，不是数值评分核对。结果仍标为 `pending_stage_check`，最终按阶段提示验收。超时或重新变为「录音」且回放不可用时，保留待核实状态；平台明确提示未完成后只补缺失句，不因分数或未知结果盲目重发。普通模式保留原有分数检查。

数字输入在确认录音提交后先释放策略，再只读等待保存入口，避免上传等待占用设备端输入策略的有界寿命。异常清理失败会附加到原始错误上，不掩盖真正的页面或坐标拒绝；没有释放确认时仍停止后续音频。

`followread-results.json` 记录句序、实际动作时间与音频，并保留数字音频时长、字节数、释放状态及待阶段验收标记；旧记录缺字段时不能视为零或释放失败。`bridge-recording.jsonl` 区分准备、录音、提交状态。`--start-at` 来自实机和这些证据，程序不会仅因已有缓存就跳过未录句。

## AI 对话

读取主题和实际话轮要求；回答数组包含从第 1 轮起的全部已审阅回答，程序根据当前接受计数继续。用户允许通用短句时可提前准备与主题相关的约 5 秒语音，其他情形按实际问题准备回答。

```powershell
python <固定副本>/dialogue_session.py --responses <完整回答数组.json> --port 8794 --display-id <逻辑ID> --capture-display-id <SurfaceFlingerID> --uid <本次UID> --xy <按住按钮X> <Y>
```

先核对 AI 音频气泡已就绪，再注册单轮输入策略；按住状态出现后才送声音，finally 释放本次副屏上的同一个按点。每轮必须确认接受计数恰好加 1，达到目标立即结束。未知结果、计数异常或控件改变时停止，不能重新发送同一回答。既有默认主屏接口仍保留，副屏必须显式提供映射、UID 和当前按钮坐标。

同一话轮内 AI 文本可能继续生成，输入前允许只读等待文字稳定并重新关联音频气泡；话轮变化仍停止。当前唯一气泡已经暴露正时长文本时直接读取该状态，省去重复截图；只出现旧气泡时长或当前 0 时长不能通过，缺少可读时长时保留像素校准路径。

## 复述和自由表达

复述先启 UID 内部采音，再播放并核对实际句子；已见关键词提示、英文句首附中文翻译入口两种布局。完全匹配时复用跟读 WAV，分句或匹配不唯一时交回判断。短暂静音不是通用的播放结束证明，不能据此自动补成完整范例或重播。每题等「回放」和「重录」出现再下一题，最后提交并确认阶段完成。常驻 worker 的 `transcribe` 命令可复用模型；不能为纯转写另开一个持有手机桥连接的 worker。

按真实音频、题目要点及时间要求准备回答；长语音在注册策略之前全部合成、检查实际 WAV 时长。复用 `audio_injection_trial.tap_turn(session, wav, x, y, guard)`，其中 `guard` 必须验证当前阶段与具体题目；不能把 Pre 的词头守卫用于其他页面。

```python
result = inject_once(session, runtime, wav, uid, evidence_dir,
                     lambda: tap_turn(session, wav, x, y, current_prompt_guard),
                     max_seconds=reviewed_duration_limit)
```

`reviewed_duration_limit` 是依据实际 WAV 设定的 1–120 秒整数上限，默认 20 秒保持兼容。握手必须确认探针支持该上限，且 UID、采样率、声道、字节数和时长一致，才会触发录音。`tap_turn` 只完成有界录音，返回 `pending_app_readback`；后续要等实际提交按钮可用、提交并确认离开该录音页，不能把音频播完当作平台保存。

阶段卡已完成但显示「报告生成中」时，周计数可能稍后才更新。只读等待并刷新任务页核对，不能因返回后的第一帧还是旧计数就重复提交；不需要读取数值评分。

## 恢复与验收

页面过渡的空窗口或暂失目标焦点最多只读等待 3 秒；锁屏、未知输入结果和真实遮挡仍停止。副屏保留外来窗口保护，短暂过渡不允许重发点击。显示迁移后重新枚举映射，不能沿用旧显示 ID。

桥服务逐个处理连接，60 秒无读写会关闭当前连接。长录音期间不要另开客户端查询手机；用当前执行器或已落盘事件观察进度。长录音后的窗口查询允许一次只读重连并重新建立状态，不重播声音、不重发未知点击。录音已自动结束并出现提交按钮时直接按当前状态提交。

每阶段检查实际进度，最后核对平台本周计数。汇报分开稳定运行、音频、初始化和恢复耗时；完整实测范围以[验证记录](VALIDATION.md)为准。
